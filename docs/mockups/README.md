# Mockups

Design explorations from 2026-09-19, rendered on the real library with placeholder posters and the six shipped Omarchy palettes. Open either `index.html` in a browser; everything is static.

- `all-six/`: the six proposed looks in one page. Bracket keys switch look, backslash cycles the theme. Marquee, Filmothèque, Shelf, Mosaic, Terminal, Éditorial. `CONTRACT.md` is the brief each variant was built against.
- `filmotheque/`: the chosen look on its own. The Slint app follows `../design-direction.md`, which was written from it.

The mockups' UI copy is French; the app's is English.
